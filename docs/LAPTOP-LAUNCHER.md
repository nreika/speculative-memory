# ノートPC（msi）の起動アイコンと自動起動（2026-10-21）

ユーザーの依頼：「両PCで、Claude を起動せずに動かせるようにして。デスクトップにアイコンを置いて、それを押せばサーバーが立ち上がってメイン画面が出るようにして。PC 再起動時に自動でサーバーが起動するようにして。」

メインPC（emergent-2）は対応済み。

- デスクトップの「Speculative Memory」アイコン → `scripts\launch-main.ps1`。動いていない ComfyUI :8001 と Node :3000 だけを起動し、`http://127.0.0.1:3000/control/` を開く。
- ログオン時の自動起動：タスク スケジューラの「SpeculativeMemory ComfyUI 8001」「SpeculativeMemory Node 3000」（`scripts\install-autostart.ps1` で登録済み）。

## ノートPCでやること（ノートの Claude セッションか、ユーザーが一度だけ行う）

ノートで動かすのは、カメラ入力ブリッジ（`native_input.py`、Tailscale の 100.77.14.9:8767）と Ollama（qwen3-vl:4b-instruct、:11434）。ブリッジのコードはノートにしかないので、パスはノートで確認すること。

1. **起動スクリプト**（例：`start-speculative-memory.ps1`）を作る。中身は次のとおり。
   - Ollama が :11434 で応答しなければ起動する（スタートメニューの Ollama アプリ、または `ollama serve` を隠しウィンドウで）。
   - ブリッジが :8767 で LISTEN していなければ、今の手動起動と同じコマンドで、隠しウィンドウで起動する。
   - 両方の応答を最大 2 分待ち、ログを残す。
   - 最後にメインPCの MAIN 画面 `http://100.66.171.99:3000/control/` を既定のブラウザで開く。
   - すでに動いているものには触らない（2 回押しても安全）。
2. **デスクトップアイコン**：上のスクリプトを `powershell.exe -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File <スクリプト>` で実行するショートカットを、デスクトップに「Speculative Memory」という名前で置く。
3. **自動起動**：タスク スケジューラに「ログオン時」トリガーのタスクを登録し、同じスクリプトを実行する（ただしブラウザは開かない引数を付ける）。設定は、ログオン中のみ実行・制限付き権限・失敗時 1 分おきに 3 回再試行・実行時間の制限なし。メインの `scripts\install-autostart.ps1` と同じ形にする。
4. **確認**：ノートを再起動してログオンし、メインの MAIN 画面で INPUT にカメラ映像が出ることと、Ollama が緑になることを確かめる。

## 注意

- 自動起動は「ログオン時」。Windows の起動後にログオンするまでは動かない（ログオンなしで動かすにはパスワードの保存が必要になるため、使わない）。
- トークンやパスワードはスクリプトに書かない。ブリッジのトークンは今の保存場所をそのまま使う。
